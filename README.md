# 报价贴

将已有进价表整理成客户报价的小工具。AI辅助开发，首版试卖；尚无客户成交案例。

## 先试用

下载[5条试用包](./报价贴_试用包.zip)，解压后用电脑Chrome或Edge打开HTML，也可以下载本仓库的index.html直接打开。页面自带合成示例，不是市场行情。

从Excel/WPS复制商品、规格、成本价三列，或读取UTF-8 CSV；设置固定加价和成本上浮比例，核对每行配置与售价后导出客户报价图、CSV、文本，或通过浏览器打印保存PDF。客户导出不带成本列。单文件、无账号、无订阅、无外部脚本/API，不自动保存历史或发送报价。

## 价格与范围

5条免费试用。完整版暂定人民币49元买断，一个商家内部使用，单次最多500条，单张PNG最多50条。图片识别、实时行情、库存和订单不在范围内。购买前请先确认自己的三列格式适用。此仓库包含试用版，不包含完整版商业交付文件。

需要完整版可在本项目Issue中提出购买咨询，说明希望解决的格式问题即可。请不要公开发送真实进价表、私人联系方式或支付凭证。具体范围和收款方式在私下确认后再付款；目前没有自动付款页面。

## 实际核验

已检查金额精度、向上取整、逐行核对、错误行阻断、重复行保留、CSV内容、5条限制和离线PNG生成。已查看桌面与390像素宽度预览，并生成本地PNG/PDF样例。浏览器下载设置仍可能影响保存，请以自己的试用结果为准。

试用包可原样转发试用；完整版仅供购买商家内部使用。不要把试用版当作开源商业授权。
